# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub:
[Security > Report a vulnerability](https://github.com/AdamoElProfesor/SmartBnB/security/advisories/new).
Include what you found, how to reproduce it and the impact you expect.

You can expect a first answer within a week. Once the issue is fixed, you will
be credited in the advisory if you wish.

## Scope

- The code in this repository.
- The live site [smartbnb.ch](https://www.smartbnb.ch) and its API.

Please do not run automated scans or load tests against the live site: it
runs on free hosting tiers and a shared daily AI quota.
